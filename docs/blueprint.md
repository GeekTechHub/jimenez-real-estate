# **App Name**: Caribbean Estates

## Core Features:

- Dynamic Hero Section: Presents a captivating title 'Invierte en el Futuro de Punta Cana' and subtitle, designed to grab attention with a clear 'Ver Catálogo' call to action that smoothly scrolls to featured projects.
- Featured Projects Display: Showcases prominent real estate projects (Lotificación Cristal, Lotificación Punta Cana) with distinct cards, each highlighting project names and strategic tags ('Pre-Venta', 'Ubicación Premium', etc.).
- Direct WhatsApp Communication: Integrates a highly visible and accessible WhatsApp button, labeled 'Habla con un asesor', pre-configured to initiate a chat with '+18098474966' for instant client engagement.
- Interactive Location Map: Embeds an interactive Google Map (iframe placeholder from 'https://maps.app.goo.gl/cSmuynCsgcuqnnEA8?g_st=com.google.maps.preview.copy') in the footer, displaying the company's physical address for easy navigation.
- Mobile-First Responsive Design: Ensures the entire landing page fluidly adapts and maintains an optimal user experience across all device sizes, with a focus on responsiveness for mobile phones and Chromebooks.
- AI-Powered Project Naming & Tagging Tool: An internal generative AI tool to assist real estate agents in creating compelling names and strategic marketing tags for new projects based on their features and target market, to enhance promotional content for platforms like the landing page.

## Style Guidelines:

- The visual design will capture a 'Lujo Caribeño' aesthetic using the specified palette: A dark professional blue (Blue-900: #1E3A8A) as the primary brand color, bright amber (Amber-500: #F59E0B) for luxury accents and calls to action, and a clean off-white (Slate-50: #F8FAFC) as the background, fostering an inviting and high-end feel.
- Headline and body font: 'Inter' (sans-serif), providing a modern, clean, and highly legible aesthetic suitable for both prominent titles and detailed descriptions. Note: currently only Google Fonts are supported.
- Minimalist, line-based icons for property features or actions, reflecting sophistication and clarity, enhancing the overall 'luxury' theme.
- A spacious and uncluttered single-page layout emphasizing readability, clear calls to action, and intuitive flow between sections (Hero, Projects, Contact, Footer).
- Subtle, smooth transition effects for elements appearing on scroll or on hover over interactive components like project cards and buttons, providing a refined user experience without being distracting.
